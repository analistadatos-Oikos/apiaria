# ApiarIA Full
Colmena de 1.200 agentes técnicos (120 por área × 10 dominios: SQL, Python, M, Sheets, Excel, GAS, JS, CSS, HTML, Arquitectura) con debate cruzado, síntesis con tabla comparativa, flor en vivo y **red neuronal de solicitudes**. Gemini gratis por defecto.

Despliegue: sube `index.html`, `hive.js`, `providers.js` y `conector-drive.gs` a un repo público → Settings → Pages → main /root. Instrucciones completas en `INSTRUCCIONES.txt`.
